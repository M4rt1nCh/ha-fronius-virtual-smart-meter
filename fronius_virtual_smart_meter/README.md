# Fronius Virtual Smart Meter

Aggregate inverter data — from **Home Assistant entities** — into a single **virtual Fronius SunSpec smart meter** that a Fronius
GEN24 / Symo GEN24 Plus discovers over Modbus TCP (on Home Assistant's own IP),
so generation from extra inverters (e.g. Growatt) is counted as production.

See the **Documentation** tab for setup, configuration, and troubleshooting.
